# Lista de pendientes antes de publicar

Marca cada casilla cuando lo completes. Todo lo que ponga `[PENDIENTE]` en la web
viene de aquí.

## Imprescindible para que funcione
- [ ] **WhatsApp:** sustituir `TUNUMERO` por el número real (p. ej. `34612345678`). *(index.html)*
- [ ] **Email:** sustituir `TU_EMAIL@nidoostudio.es` por el correo real. *(index.html y páginas legales)*
- [ ] **Formspree:** crear formulario y sustituir `TU_CODIGO`. *(index.html — ver README punto 4)*

## Contenido de la web
- [ ] **Frase diferenciadora** del hero (debajo de los botones). ¿Qué os hace distintos? (p. ej. “primer vídeo sin compromiso”, “entrega en 48 h”).
- [ ] **Instagram:** usuario real (`TU_INSTAGRAM`).
- [ ] **Precio:** confirmar qué incluye el “Desde 80 €” y si el IVA va incluido o no.
- [ ] **FAQ — plazo de entrega** (cuántos días tardáis).
- [ ] **FAQ — política de cambios/revisiones**.
- [ ] **FAQ — número de fotos** que necesitáis.
- [ ] **Trabajos:** sustituir las 6 imágenes de relleno por pósters o vídeos reales (`assets/work-1.svg` … `work-6.svg`).
- [ ] **Foto del hero** (`assets/hero.svg`) por una foto vertical real de un alojamiento.
- [ ] **Imagen de la sección “problema”** (`assets/problem.svg`).
- [ ] **Imagen para redes** `assets/og-image.png` (1200 × 630 px).

## Datos legales (obligatorio en España)
- [ ] **Aviso legal:** titular, NIF/CIF, domicilio, email, URL. *(legal/aviso-legal.html)*
- [ ] **Privacidad:** responsable, NIF, domicilio, email de contacto para derechos, proveedor de alojamiento. *(legal/privacidad.html)*
- [ ] **Cookies:** revisar si añadís analítica en el futuro (entonces hará falta banner). *(legal/cookies.html)*

## Al publicar
- [ ] Comprobar que el **dominio `.es`** está libre y registrarlo.
- [ ] Sustituir `https://nidoostudio.es` por el dominio real en `index.html`, `sitemap.xml` y `robots.txt`.
- [ ] Subir a GitHub Pages (ver README punto 7).
- [ ] Probar el formulario enviando una solicitud de prueba.
- [ ] Probar en un iPhone real que todo se ve bien.

## Opcional (recomendado)
- [ ] Optimizar todas las imágenes a **WebP** (ver README punto 3).
- [ ] Alojar las tipografías en el servidor para mayor privacidad (ver README punto 8).
- [ ] Dar de alta la web en **Google Search Console** y enviar el `sitemap.xml`.
